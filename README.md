# Dental Study Material (MDS)
Textbook-sourced study notes with page-cited references.
- Module 1 — Conservative & Restorative Dentistry
- Module 2 — Endodontics (8 sub-modules)
- Module 3 — Dental Materials & Material Science

`markdown/` = Obsidian-ready notes; `docx/` = original Word files.

## Textbooks
`textbooks/` holds the source textbooks as chapterwise Markdown (Conservative Dentistry, Endodontics, Dental Materials). Study notes link to their source books and to matching chapters via the topic hubs in `markdown/_Topic Hubs/`. Open the repo folder as an Obsidian vault (or copy `markdown/` + `textbooks/` into one) to use the graph view.
